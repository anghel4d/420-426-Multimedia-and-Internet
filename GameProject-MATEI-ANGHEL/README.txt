SPACEX DANDY
// Game project for 420-426 (Multimedia and Internet) at John Abbott College
// By Matei Alexandru Anghel

1. DESCRIPTION:
    This is a 2d rocket run game inspired by the SpaceX corporation's ruthless innovation
    over the course of the past decade. It has the player controlling a Starship rocket on a 
    mission to planet Mars from Earth, with several stages of flight. There are certain powerup 
    unlocks which persist between runs, which are unlocked through progress.

2. INSTALLATION:
    None required. This is an HTML-CSS-JavaScript game and should run natively on any modern browser
    Just open up index.html and you're set!

3. CREDITS:
    - Code and design all by Matei Anghel
    - Visual assets based on real ultra-compressed photographs turned into pixel art
    - Music from "Space Dandy" OST
